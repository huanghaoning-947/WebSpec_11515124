# POISON COFFEE 一頁式網站詳細規格

> 規格來源：`WebPage_11515124/outline/index.html`（逆向整理）  
> 學號：11515124  
> 頁面型態：單頁式品牌介紹、商品展示、購物車互動與預約表單  
> 文件用途：作為後續修改網站內容、樣式與互動的工作規格。

## 1. 專案概述

- 品牌名稱：中毒咖啡 / POISON COFFEE（依頁面標題、品牌區及頁尾識別整理）。
- 產品定位：以「毒性、中毒、沉淪」作為咖啡風味的誇飾修辭，呈現高辨識度的暗黑實驗室視覺；頁尾另有風格說明，表示毒物用語是風格象徵，產品為天然咖啡豆。
- 頁面目標：建立品牌印象、說明產品與手沖方式、提供商品加入購物車，以及 VIP 體驗／訂購表單入口。
- 語系：HTML `lang="zh-Hant"`，預期內容為繁體中文並混用英文品牌與風味字樣。
- 實作方式：單一 HTML 檔內含 CSS 與 JavaScript；外部字型由 Google Fonts 載入。

## 2. 頁面架構與導覽

頁面為垂直捲動的一頁式架構，Header 固定於頂部，導覽連結使用錨點跳至以下區段：

| 順序 | 區段 | ID | 主要用途 |
|---:|---|---|---|
| 1 | Hero 首屏 | `home` | 品牌主張、主要行動按鈕、數據摘要及主視覺卡片 |
| 2 | 品牌理念 | `philosophy` | 三張品牌理念／品質支柱卡片 |
| 3 | 商品豆單 | `menu` | 分類篩選、四項商品卡、毒性指數、價格及加入購物車 |
| 4 | 手沖步驟 | `protocol` | 手沖流程、四個步驟、計時器及步驟狀態 |
| 5 | 顧客評價 | `reviews` | 三則顧客心得卡片 |
| 6 | 預約與訂購 CTA | `booking` | VIP／訂購說明及訂購表單 |
| 7 | Footer | — | 風格說明、品牌資訊、快速連結、商品規格與聯絡資訊 |
| 8 | 購物車抽屜 | `cartDrawer` | 浮層購物清單、數量調整、總額與結帳按鈕 |
| 9 | Toast 訊息 | `toastBox` | 加入購物車、結帳及表單提交等操作回饋 |

### 2.1 Header

- 固定定位於視窗上緣，桌面高度約 76px；深色半透明底、背景模糊與細邊框。
- 左側品牌標誌由圓形綠色圖示、中文品牌名及英文副標組成。
- 中間導覽連結指向 `#home`、`#philosophy`、`#menu`、`#protocol`、`#reviews`、`#booking`。
- 右側有購物車按鈕及商品數量徽章；窄螢幕顯示漢堡選單按鈕。
- 導覽連結 hover 時文字變亮並顯示綠色底線；購物車 hover 顯示綠色外框／光暈。

### 2.2 Hero 首屏

- 全視窗高度為基準，內容垂直置中；上方留白避開固定 Header。
- 桌面為雙欄：左側品牌文字、CTA、四項數據摘要；右側主視覺卡片。
- 背景包含細網格、綠紫色模糊光暈，光暈緩慢脈動。
- 左側包含狀態標籤（閃爍圓點）、主標題（局部螢光綠）、描述及兩個按鈕：前往商品豆單、了解品牌理念。
- 下方四欄數據摘要，以大字數值搭配小字標籤呈現。
- 右側卡片以 CSS／SVG 繪製手沖濾杯及滴落動畫，附品項名稱、英文描述與風味標籤；不依賴外部照片。

### 2.3 品牌理念區

- 深色表面背景，上下細邊框；置中區段眉標、標題及說明。
- 三欄理念卡片，使用 01–03 編號、線性 SVG 圖示、標題及描述。
- 卡片 hover 上浮、綠色邊框及陰影增強。

### 2.4 商品豆單區

- 深色背景，置中區段標題及說明。
- 上方分類按鈕列，包含「全部」與三種商品類別；目前啟用分類以綠色文字、邊框及淡色底表示。
- 商品以四欄 Grid 排列；每張卡片包含：角標、SVG 商品圖、產地／類別、品名、風味描述、毒性指數及進度條、價格、加入購物車按鈕。
- 商品圖為漸層色塊與 SVG 圖示，hover 時放大並微旋轉；卡片 hover 上浮並出現綠色光暈。
- 頁面商品包含黑曼巴（Black Mamba）、曼陀羅花（Datura Blossom）、烏頭／Aconite Reserve、水滴類特調等四項；原始中文部分受編碼亂碼影響，完整名稱、風味及價格應以修復後的來源文字核對。
- 商品分類由按鈕 `data-filter` 與卡片 `data-category` 對應；初始顯示全部商品。

### 2.5 手沖流程區

- 區段包含標題、簡介與雙欄內容：左側計時器面板，右側四步驟清單。
- 四步驟主題為研磨秤豆、悶蒸、分段注水／渦流滴濾、完成萃取；各項附操作說明與水量、溫度、時間等參數。
- 計時器顯示 `mm:ss`，提供開始／暫停與重置按鈕；步驟項目可點選高亮。
- 計時階段依秒數切換說明並高亮目前步驟；到達流程尾段顯示完成／移開濾杯提示。
- 手沖視覺以儀表面板、計時數字與步驟狀態構成，延續暗色科技感。

### 2.6 顧客評價區

- 置中區段標題及說明，下方三欄心得卡片。
- 每張卡片包含星等、引言、圓形字母頭像、顧客姓名與身份描述。
- 卡片深色底、細邊框、圓角，與全站卡片風格一致。

### 2.7 預約／訂購區

- 以突出式 CTA 容器呈現 VIP Dark Bar 預約及線上訂購說明。
- 表單欄位：姓名（必填）、Email（必填）、咖啡豆選擇、服務模式選擇；底部全寬提交按鈕。
- 姓名與 Email 使用 label 對應欄位 ID；Email 使用 `type="email"`；表單由 `handleFormSubmit(event)` 處理。
- 目前提交流程為前端示意：阻止瀏覽器預設送出，顯示確認 Toast 並重設表單；沒有後端送單串接。

### 2.8 Footer

- 頂部設置風格說明 Banner，搭配警示圖示；說明「中毒」等用語為咖啡香氣的修辭，並聲明商品為天然咖啡。
- 下方四欄：品牌簡介、快速導覽、商品規格、店舖／聯絡資訊。
- 底部顯示版權、學號及規格文件路徑。
- 文字連結回到對應錨點；實際營業資訊與電話內容需由需求方確認。

### 2.9 購物車抽屜與 Toast

- 購物車由遮罩 `cartOverlay`、抽屜 `cartDrawer`、品項清單、數量、總額及結帳按鈕組成。
- 點擊 Header 購物車、遮罩或關閉按鈕切換抽屜顯示狀態。
- 空車顯示空狀態提示；有品項時呈現品名、單價、數量與 +/- 控制。
- Toast 固定浮在頁面角落，短暫顯示操作結果後自動隱藏。

### 3.2 字體與排版

- 內文：`Noto Sans TC`，備援系統無襯線字體；基礎字級 16px、行高 1.7。
- 標題：`Noto Serif TC`，字距約 `.04em`。
- 英文裝飾與數字：`Cinzel`，字距約 `.12em`。
- Google Fonts 預載入：Cinzel（500、700、900）、Noto Sans TC（300、400、500、700）、Noto Serif TC（400、600、700、900）。
- 主標題採 `clamp(38px, 5.2vw, 64px)`；區段標題採 `clamp(30px, 3.8vw, 44px)`。
- 文字採高對比白字與灰藍色次要文字；綠色用於強調，不作大面積正文底色。

### 3.3 間距、容器與元件

- 全域 `box-sizing: border-box`，元素 margin／padding reset 為 0；頁面平滑捲動並限制橫向溢出。
- 主要容器寬度：`min(1200px, calc(100% - 48px))`，水平置中。
- 一般區段上下 padding 約 100px。
- 按鈕採 4px 圓角、粗體、字距 `.08em`；主按鈕為螢光綠實心，次按鈕為透明底白色細框。
- 卡片圓角主要為 12px；品牌圖示圓形；篩選按鈕膠囊形。
- hover 慣用約 0.25–0.4 秒過渡，並搭配上浮、邊框變色或陰影變化。

## 4. 響應式行為

來源 CSS 設有 `max-width: 1024px` 與 `max-width: 768px` 兩組媒體查詢。

- 桌面版：Hero 雙欄；理念三欄；商品四欄；評價三欄；導覽水平排列。
- 1024px 以下：各 Grid 欄數與間距收斂，避免商品卡過窄；Hero 及主要雙欄區調整比例。
- 768px 以下：導覽收合為漢堡按鈕；點擊後切換 `.open` 狀態，點選導覽連結後關閉。
- 小螢幕：Hero、理念、手沖及預約表單改為單欄或適合窄螢幕的排列；商品、評價卡片減少欄數；按鈕與表單欄位允許換行或全寬。
- 手機需保留固定 Header 下的內容空間、可操作的觸控尺寸及不產生水平捲動。

> 具體欄數及個別 CSS 數值應在編輯前以來源檔媒體查詢核對；此文件記錄可辨識的整體行為與斷點。

## 5. 互動與資料行為

### 5.1 商品篩選

- 點擊分類按鈕後，移除其他按鈕 `.active`，將選取按鈕標記為 active。
- 讀取按鈕 `data-filter`，依商品卡 `data-category` 顯示／隱藏；`all` 顯示全部。

### 5.2 購物車

- 資料結構為記憶體中的 `cart` 陣列，每筆品項包含 `title`、`price`、`qty`。
- 新增同名商品時增加數量；不同商品新增一筆。
- `updateCartUI()` 更新 Header badge、抽屜品項數、總價及空狀態。
- 數量加減即時更新；數量降至 0 時移除品項。
- 結帳時若購物車為空，顯示提示；否則顯示完成提示、清空購物車並關閉抽屜。
- 目前沒有伺服器、付款或持久化儲存；重新整理後購物車會重置。

### 5.3 手沖計時器

- `startTimerBtn` 開始／暫停每秒計時；`resetTimerBtn` 清除計時、歸零並回到第一步。
- 顯示格式為兩位數分鐘與秒數。
- 時間區段依序更新階段說明及目前步驟高亮；使用者可點選步驟手動高亮。
- 修改時需同步確認按鈕文字、階段界線及階段說明，避免計時狀態與步驟狀態不一致。

### 5.4 表單與 Toast

- 表單使用瀏覽器原生 required／email 欄位驗證。
- 提交事件阻止頁面重載，讀取姓名及豆款選擇，顯示確認 Toast，再重設欄位。
- Toast 由 `showToast(message)` 設定訊息、顯示狀態，約 3.5 秒後自動隱藏；新訊息會重設計時器。

## 6. 可維護性與修改注意事項

- 錨點 ID、導覽連結及 Footer 快速連結需保持一致。
- 商品標題、價格、分類及加入購物車按鈕需使用同一組資料，避免篩選或金額不一致。
- 所有動態金額以新台幣顯示；購物車總額依單價乘數量計算。
- SVG 裝飾及背景光暈不應遮擋文字或按鈕。
- 固定 Header 開啟時，錨點跳轉需避免區段標題被 Header 遮住；可視需要設定 `scroll-margin-top`。
- 表單目前只是前端示意。若需真實預約或付款，另需明確定義 API、驗證、成功／錯誤狀態及隱私告知。

## 7. 來源檔待確認項目

1. **文字編碼／繁中內容**：目前讀取來源時，頁面標題、描述、中文文案、按鈕文字及部分程式字串呈現大量亂碼。修改前須確認檔案實際編碼與原始正確文案，統一以 UTF-8 儲存。
2. **JavaScript 可執行性**：部分亂碼字串在讀取結果中看似引號或標籤不完整。需以修復後來源確認 JavaScript 語法、商品新增與計時器事件是否可正常執行。
3. **品牌與商品資料**：逐項確認四款商品的正式名稱、產地、風味、分類、價格、指數值與標籤；目前只能可靠辨識部分中英文名稱。
4. **聯絡／營業資訊**：電話、地址、營業時間與 VIP 名額等內容需確認是否為示意資料。
5. **無障礙**：確認漢堡按鈕有 `aria-expanded`／`aria-controls`、購物車與 Toast 有適當狀態宣告、鍵盤焦點清楚；可補上 reduced-motion 支援。
6. **小螢幕細節**：此規格確認 1024px、768px 斷點存在，個別 Grid 欄數及表單排列請以來源 CSS 最終核對。
